# Contributing to Antigravity Remotion Engine

Thank you for considering contributing to this project!

## Getting Started

1. Fork the repository
2. Clone your fork locally
3. Install dependencies with 
pm install
4. Create a feature branch from main

## Development

- TypeScript source lives in src/
- Python engine code lives in src/engine/ and ramework/
- After Effects scripts are in the root as \.jsx\ files
- CLI utilities are in scripts/

## Code Style

- Use TypeScript for all new frontend code
- Use Python 3.11+ for engine modules
- Follow existing naming conventions
- Keep functions focused and modular

## Pull Requests

- Write clear commit messages
- Keep PRs focused on a single feature or fix
- Update documentation as needed
- Test your changes before submitting

## Reporting Issues

- Use GitHub Issues for bug reports
- Include reproduction steps when possible
- Specify your OS and software versions
