# Changelog

All notable changes to the Antigravity Remotion Engine will be documented in this file.

## [1.0.0] - 2026-08-22

### Added
- Initial release of Antigravity Remotion Engine
- Core video composition engine with Remotion integration
- After Effects JSX build scripts for automated project creation
- Audio analysis pipeline with beat detection and feature extraction
- Subtitle extraction and captions layer
- Multiple visual effects: chromatic aberration, film grain, glow shader, vignette
- Camera system with beat-synced movement
- Lower third and typography components
- Transition effects including whip pan
- Motion blur and speed ramp utilities
- LUT engine for color grading
- Webpack-based asset discovery
- CLI tools for preset export and timeline segment generation
- QA gate with automated quality metrics
- Pipeline profiler and watchdog
- Futuristic AI style planner
- Python-based engine for backend processing
