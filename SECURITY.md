# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please send an
email to the maintainers. All security vulnerabilities will be promptly
addressed.

Please include the following information when reporting:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)
