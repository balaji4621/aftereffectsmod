2. IN-DEPTH TECHNICAL BREAKDOWN & BUILD PROCESS
================================================================================

STEP 1: INGESTION & OFFLINE DSP ANALYSIS
- `scripts/discover-assets.mjs` probes media files, generates `src/generated/manifest.json`, and 
  automatically creates 720p/30fps proxies for 4K video inputs.
- `scripts/analyze-audio.mjs` calculates multi-band spectral flux (sub/kick, snare, transients) 
  and writes `src/generated/audio-features.json`.
- `scripts/extract-subtitles.mjs` performs word-level forced alignment writing `src/generated/subtitles.json`.
- `src/schemas/` validates JSON outputs at runtime using Zod.

STEP 2: DUAL-ENGINE MOTION PARITY
- `src/utils/motion.ts` exposes 4-point Cubic Bézier vectors `[x1, y1, x2, y2]` evaluated via `bezier-easing`.
- `scripts/ae_helpers/bezier.jsx` translates these vectors into After Effects `KeyframeEase` objects.

STEP 3: UNIFIED ADOBE AFTER EFFECTS BUILDER
- `build_ae_master.jsx` dynamically loads manifests and presets (`ae_presets/masterpiece.json`, `phonk.json`) 
  using OS-agnostic relative paths (`$.fileName`).
- Structured error logs are written to `out/logs/ae_build_<timestamp>.json`.

STEP 4: REMOTION REACT & FUTURISTIC AI LAYER
- `BeatSyncedCamera.tsx` applies 3D translation/rotation impulses driven by audio spectral flux.
- `WebGLShaderPass.tsx` renders procedural chromatic aberration and film grain overlay.
- `CaptionsLayer.tsx` presents dynamic karaoke text with word spring scaling.
- `futuristic_ai.py` generates optical flow speed ramps, synthetic depth maps, and subject matting masks.

STEP 5: WEB UI & AUTOMATION RUNNER
- `server.py` hosts a web server at `http://localhost:8000` with automated output cleanup.
- CLI scripts: `npm run ingest`, `npm run render:remotion`, `npm run render:ae`.
